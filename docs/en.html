Windows · VPN tunnel watcher · HTML UI

Roblox VPN Gate

Connect VPN — Roblox opens. Disconnect — the tab closes instantly. Watches the tunnel, not the VPN app window.

Download installer GitHub
01

Tunnel detection

Polls VPN adapters and RAS. An open client without a tunnel does nothing.

02

Tab open

On offline → online edge, opens Chrome/Edge at your URL.

03

Instant close

When the tunnel drops, the tab closes without manual cleanup.

Interface

Dark HTML UI with themes, event log, and adapter tuning.

Install in a minute

  1. Download RobloxVPNGate-Setup-1.0.0.exe from Releases
  2. Install and launch the app
  3. Start monitoring and connect your VPN as usual

Requirements

Windows 10/11 and Google Chrome or Microsoft Edge. WebDriver downloads on first run.
